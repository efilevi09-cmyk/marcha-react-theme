# מרשה בלרינה – רשימת ליקוט

תוסף וורדפרס שמוסיף פעולה קבוצתית במסך ההזמנות של ווקומרס ומפיק **רשימת ליקוט מאוחדת** לכמה הזמנות יחד.

נבנה כי אף אחד מתוספי ההדפסה החינמיים לא כולל pick list אמיתי — הוא קיים רק בתוסף הרשמי בתשלום (79$ לשנה).

## מה הוא עושה

במסך **הזמנות** מופיעה פעולה קבוצתית חדשה: **"רשימת ליקוט למחסן"**. מסמנים הזמנות, בוחרים אותה, ונפתח דף הדפסה אחד שמאחד את כולן.

- **שורה לכל צירוף של דגם ומידה** — "קטיפה שחורות · 38 — 3 זוגות". זו היחידה שהמלקטת עובדת מולה, לא ההזמנה.
- **תמונת מוצר בכל שורה** — עם 80 דגמים שנבדלים בגוון, שם בלבד לא מספיק.
- **מקובץ לפי קטגוריית מוצר** — הליכה אחת על פני המדפים, בלי הלוך ושוב.
- **עמודת סימון** לסמן בעט תוך כדי.
- **מספרי ההזמנות בכל שורה** — אם מידה חסרה במלאי רואים מיד את מי זה משפיע.
- כותרת עם מספר ההזמנות, מספר השורות וסך הזוגות.

## למה HTML ולא PDF

הדף הוא HTML רגיל שמודפס מהדפדפן, בלי מנוע PDF באמצע. זה מכוון: מנועי ה-PDF של תוספי ההדפסה הנפוצים לא תומכים ב-RTL, והעברית יוצאת שבורה. הדפסה ישירה מהדפדפן נותנת עברית תקינה, A4 נקי, ותמונות.

## התקנה

1. להוריד את התיקייה `marcha-pick-list` כקובץ zip.
2. וורדפרס → תוספים → הוספת תוסף → העלאת תוסף.
3. להתקין ולהפעיל.

## בטיחות

התוסף **קורא בלבד**. הוא לא כותב למסד הנתונים, לא משנה הזמנות, לא נוגע בתשלומים ולא טוען דבר בחזית האתר — כל הקוד רץ רק בצד הניהול.

הרשאה נדרשת: `manage_woocommerce`. הדף מוגן ב-nonce.

תואם גם לאחסון ההזמנות הישן (post table) וגם ל-HPOS.

## דרישות

- WordPress 6.0+
- PHP 7.4+
- WooCommerce
